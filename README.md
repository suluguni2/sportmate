# SportMate
SportMate — веб-приложение для организации спортивных мероприятий.

Приложение позволит пользователям создавать спортивные встречи, находить подходящие мероприятия и записываться на них.

На первом этапе разрабатывается REST API без графического интерфейса и авторизации.

## Функциональность MVP

| Функциональность                      | Этап разработки | Как реализовать                                 |
| ------------------------------------- | --------------- | ----------------------------------------------- |
| Создание мероприятия                  | Запланировано   | POST-запрос, проверка данных, сохранение в БД   |
| Просмотр мероприятий                  | Запланировано   | GET-запрос, получение списка из БД              |
| Просмотр мероприятия по ID            | Запланировано   | GET-запрос, поиск мероприятия по идентификатору |
| Создание участника                    | Запланировано   | Создание пользователя с уникальным ID           |
| Запись на мероприятие                 | Запланировано   | Связь участника с мероприятием в БД             |
| Отмена записи                         | Запланировано   | Удаление записи участника из БД                 |
| Ограничение количества участников     | Запланировано   | Проверка свободных мест перед записью           |
| Защита от повторной записи            | Запланировано   | Проверка существующей записи участника          |
| Тестирование                          | Запланировано   | Проверка функциональности с помощью JUnit       |
| Фильтрация мероприятий по виду спорта | Запланировано   | SQL-запрос для фильтрации по названиям          |
## Технологии

- Java 21 — язык программирования.
- Spring Boot — основа серверного приложения.
- Spring MVC — обработка HTTP-запросов.
- Maven — управление зависимостями и сборка проекта.
- Spring JDBC — взаимодействие с базой данных.
- H2 — база данных на этапе MVP.
- JUnit — автоматизированное тестирование.
- Git и GitHub — контроль версий.
